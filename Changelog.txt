Release 1.0.6
=============

 * QiCborMapper: models to and from CBOR (RFC 8949), the binary twin of
   QiJsonMapper. Raw bytes stay raw, date-times and 64-bit integers keep their
   types, and decoding streams straight into models. Roughly 20-35% smaller and
   twice as fast to encode as JSON; built into Qt Core, so no new dependency.
 * Packaging: a working vcpkg port (vcpkg/ports/qivot) and Conan 2 recipe
   (conan/), both giving find_package(Qivot) / Qivot::qivot. The CMake install
   now ships every public header (qikeyset.h, qiconnectionpool.h, qiasync.h)
   and passes -Wno-invalid-offsetof on to consumers.
 * Release workflow refuses a tag that disagrees with CMakeLists.txt.

Release 1.0.5
=============

 * Conan dependency files. The library reports itself as 1.0.4 (the version in
   CMakeLists.txt was not bumped).

Release 1.0.4
=============

 * Connection pool: threads that already hold a connection follow configure()
   (fixes iOS).

Release 1.0.3
=============

 * Connection pool: one connection per thread lifetime, removed when the thread
   ends (fixes Android). Queries start inert, with no cross-thread lookup of the
   default connection.
 * Change notifications reach every connection to the same database, on the
   hook's thread, after commit. One-row reads release SQLite's read lock.

Release 1.0.2
=============

 * DuckDB: save() writes only the changed columns.

Release 1.0.1
=============

 * save() never deletes rows: new records are INSERTed and existing ones
   UPDATEd (no REPLACE). Duplicate-key errors reach the field on SQL Server.

Release 1.0.0
=============

 * First release: single header (qivot.hpp) and full sources on every v* tag.

Each GitHub release also lists every commit since the previous tag.


Release 0.2
===========

Feature enhancements:
 * Supported to create index
 * Supported to query for more complex rules
 * New utility class to create data model initial field

Critial Changes:
 * The usage of QiWhere class is changed to adapt a faster way of usage. It is incompatible with 0.1.

Detailed Changes:

 QiWhere
 * Deprecated &,| operator overloading and removed from code. It is replaced by && and ||
 * Changed the definition of constructor. The left operand pass to constructor is restricted to data model field only. It is not compatible with old code
 * Improved the operator overloading mechanism. It become a more powerful class
 * Supported to query by compare the value on different field. The following query become possible:
  - select * from table where field1 = field2
 * New supported operators: &&,||,+,-,*,/,%,equal,notEqual,between,in,notIn,like,glob,is,isNot.
 

 QI_DECLARE_MODEL
 * Supported private field

 QiIndex
 * A new class for sqlite indexing
 
 QiField<T>
 * Supported bool and QStringList as the template type T
 * Added operator T() casting. It can be casted to T automatically.
  
 QiBaseField::get() / QiModelMetaInfo::value() - Added a new argument "convert"
 * It is true if the QVariant return should be converted to a type which is suitable for saving. It is designed for type like QStringList which is not supported by SQLite backend by default.

 QiConnection
 * Change this connection to be the default connection
 * operator == / !- compare is two connection share the same database

 QiSharedQuery
 * Added new function select()  - Construct a new query object with only the fields assigned in result 
 * Added new function orderBy() - Construct a new query object with required sorting order
 * Added new function setConnection() - Set the database connection

 QiStream
 * A new class, it provides a stream interface for reading and writing data model field

 QiListWriter 
 * A new class, it is a utility class to create the content for QiList object with predefined field 
 
 QiSharedList
 * Added new function save() - Save all the contained item to database
